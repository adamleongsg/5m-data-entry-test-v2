# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
A kernel is the main part of an operating system that manages computer resources such as CPU, memory and hardware devices. It helps software communicate with the hardware.

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
No, this is not completely accurate. WSL allows Linux to run within Windows, and both environments can share files and access system resources. They are connected rather than completely independent.

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
A terminal is an application that provides an interface for entering commands, while a shell is a program that interprets and executes those commands. For example, Windows Terminal is a terminal application, and Bash is a shell.
